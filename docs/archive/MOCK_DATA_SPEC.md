# Mock Data Spec — DEPRECATED

> ⚠️ This document describes the **pre-hack** synthetic telemetry data that
> was used before the official Infineon case was vendored. It does **not**
> match the actual task.
>
> For the real data contract used by the current pipeline, see
> [`DATA_SPEC.md`](./DATA_SPEC.md).

## Historical (pre-hack) mock data

The file `data/raw/mock_process_sequences.csv` (generated by
`scripts/generate_mock_data.py`) contains numeric sensor telemetry for a
6-step generic process:

Columns:
- `run_id`, `recipe`, `step_index`, `step_name`, `timestamp`
- `temperature`, `pressure`, `vibration`, `tool_wear`, `duration_sec`
- `next_step`, `anomaly`, `quality_label`

This shape does **not** match the Infineon task, which is symbolic step
sequence modeling over a ~120-token vocabulary with no sensor signals
(see `DATA_SPEC.md`). The old RandomForest baseline at
`src/ml/baseline.py` and the legacy Streamlit shell at `src/app/main.py`
were written against this mock spec.

These files are kept as historical context. They are not load-bearing in
the current pipeline.
