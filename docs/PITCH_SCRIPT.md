# Pitch Script — Industrial: Models that learn how processes unfold

## 30-second version
We built **Industrial: Models that learn how processes unfold**: Train a sequence model that learns industrial process trajectories and predicts the next states, bottlenecks, or anomalies. The value is that the system does not only produce an answer; it produces a measurable, explainable decision with evaluation evidence.

## 3-minute structure
1. Problem: Why this partner cares.
2. Solution: What the app does in one workflow.
3. Technical depth: What model/layer was trained or integrated.
4. Evidence: Baseline vs improved metric.
5. Demo: One realistic user scenario.
6. Impact: Cost, speed, risk reduction, or decision quality.
7. Limitation: What still needs real deployment work.

## Judge Q&A anchors
- What did you train or evaluate?
- Why is the baseline meaningful?
- What happens when data is noisy?
- How does this become useful for the partner?
- What would you do with one more week?
